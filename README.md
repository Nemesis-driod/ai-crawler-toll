# AI Crawler Toll

A  Worker that mediates access from AI/search crawlers to participating websites.

## Architecture

### V1: Non-custodial

Payments settle directly from the crawler to the participating site owner's wallet.

The service does not custody customer funds. It verifies payment and enforces access.

## Status

Phase 0 — repository, tooling, and automated quality gates.

The current Worker intentionally contains no crawler detection, payment, rate limiting, or proxy logic.
